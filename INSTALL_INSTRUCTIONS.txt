LensDNA Sovereign Agent - Chrome Extension v1.2.0
=================================================

Meet dual audio build. 🎧 in the command hub mixes Nexus into your Google Meet
seat and feeds Meet playback back into Nexus. Headphones on. Default off.

INSTALL
1. Unzip this folder. Keep all files together (manifest.json at the root).
2. Chrome → chrome://extensions/ → Developer mode ON.
3. Load unpacked → select this folder.
4. If you already had LensDNA loaded: Remove the old one, or click Reload
   on this unpacked folder so v1.2.0 replaces it.
5. Pin the icon. Open the side panel. Enter keys. INITIATE UPLINK.
6. Open meet.google.com in the same Chrome profile. Hard-refresh the Meet tab.
7. Headphones on. Click 🎧 (amber = dual audio). Stay unmuted in Meet.

If Nexus is already live and ignores Boardy: DISCONNECT, leave 🎧 armed,
then INITIATE UPLINK again.
